# OMNICOM GitHub Pages site

Source for [omnicom-digital.github.io](https://omnicom-digital.github.io), the open-source and developer showcase of OMNICOM s.r.o.

It features the [GLPI MCP Server plugin](https://github.com/OMNICOM-Digital/mcpserver) and its free, read-only edition [MCP Server Lite](https://github.com/OMNICOM-Digital/mcpserver-lite).

## Files

- `index.html`: the page content
- `style.css`: styling (dark theme, OMNICOM brand red `#c2304e` / `#c61f40`, IBM Plex Sans)

Plain HTML and CSS, no build step. GitHub Pages serves `main` as-is.
