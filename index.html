GLPI MCP Server Plugin

In development

A GLPI plugin that exposes GLPI as an MCP (Model Context Protocol) server, so AI assistants — Microsoft Copilot, Claude, and others — can work directly with tickets, the knowledge base, users and groups, and the service catalog through a standard tool interface, instead of one-off custom integrations per client.

Two permission tiers

Tool visibility follows existing GLPI profiles:

  • Standard / Central — full toolset, including user & group management, ticket updates, assignment and validation
  • Self-Service / Helpdesk — a limited subset: own tickets, FAQ, and permitted forms only

Tool registry covers

  • Ticket listing, search, detail, timeline, creation, updates
  • Followups, tasks, solutions, assignment, linking, validation approval
  • Document upload (base64 or by URL)
  • User & group management
  • Knowledge base browse, search, and CRUD
  • GLPI Forms (service catalog) — schema retrieval and submission

About Omnicom

Omnicom, s.r.o. is an IT Service Management and Enterprise Service Management consultancy based in Bratislava, Slovakia. We help organizations — including government and enterprise clients — design, implement and run their service management practice, from advisory through hands-on tool configuration.

We work across the ITSM/ESM tool landscape, with particular depth in GLPI, alongside Ausemio, HaloITSM, Lansweeper and Xurrent. Alongside client delivery, we build and open-source the tooling that makes that work repeatable — starting with the GLPI MCP Server plugin.
